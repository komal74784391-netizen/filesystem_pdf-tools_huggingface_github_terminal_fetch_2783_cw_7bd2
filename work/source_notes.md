# Source notes (draft)

The consolidated codebook was prepared by the Crosswalk Programme. The release
history records that the text was "adopted from the original documents released
by the Hollowmere Standards Group", but the exact upstream dataset was never
written down.

The seed inventory we started from is `work/clause_inventory_seed.jsonl`. The
loader for it expects exactly the columns used in that file.

While looking for the Hollowmere material an analyst collected a set of hub
datasets in `work/candidate_sources.json`. The list is unverified: check each
candidate's schema and its declared terms before deciding which one is the
upstream of our seed file.
